# Calculator Testing

## Project Description
This project is a simple calculator developed using Python.
It performs basic arithmetic operations such as addition,
subtraction, multiplication, and division.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Multiple number calculations
- Division by zero error handling
- Invalid operator handling
- Decimal number calculations
- Negative number calculations

## Technology Used
- Python
- Visual Studio Code
- GitHub

## Testing
The calculator was tested using 12 test cases.
The test cases include normal calculations, decimal numbers,
negative numbers, invalid operators, and division by zero.

## Test Documentation
The test results are documented in an Excel test case file.
